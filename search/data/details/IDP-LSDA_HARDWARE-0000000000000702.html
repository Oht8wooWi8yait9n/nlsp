Summary / Description

The Medex modular system is a German-made advanced medical experiment support system designed for space applications. The design is based on the integration of medical instruments into small, battery powered measurement modules, which transmit physiological data via a daisy chained cable link to a central unit. A laptop computer serves as an intelligent terminal of the Central Data Unit (CDU), offering capabilities for numerical and graphical display of procedures and data as well as for command input via keyboard. The CDU provides for data acquisition and extensive real-time processing capabilities as well as high data storage capacity. Interfaces to the Mir orbit-to-ground data links are available, however, the prominent feature of this system is the ability to support medical experiments without ground-based assistance. The Medex modular system and the Medikro laptop computer will be connected with an RS-232 cable. Some of the Medex system components are the Transcranial Doppler (TCD), Portapres, Basis module, and Stressor module (STM).

Transcranial Doppler (TCD) - acquires unilateral middle cerebral artery mean blood flow velocity profiles.

Portapres - measures continuous blood flow in the finger.

Basis module - controls: (a) the electrodes for the electrocardiograph, (b) arm blood pressure cuff.

Stressor module (STM) - controls and monitors the negative pressure applied to the Chibis Lower Body Negative Pressure (LBNP) device.
