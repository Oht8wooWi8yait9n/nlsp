Summary / Description

The leg press machine is a sled type device with a large non-skid footplate. Cast iron weight disks (plates) are attached directly to the sled, which are mounted on rails. The user sits below the sled and pushes it upward or outward with their feet. These machines normally include adjustable safety brackets that prevent the user from being trapped under the weight. The leg press machine can be used to evaluate a person's overall lower body strength.
