Summary / Description

Firing rate maps as a function of rat position for individual place cells - illustrate locations at which each neuron fires for Rat 3 on Escher Staircase or Magic Carpet.

These files are binary-formatted files that contain two 64x64 pixel arrays of information: the firing rate map for each place cell and a map of position occupancy by the rat during the session. To generate the arrays, the video camera image was divided into a 64x64 pixel array and the image was sampled at a rate of 60 Hz. At every sample, the position of the rat was determined and the counter in the appropriate occupancy array was incremented. The firing rate array was calculated by dividing, for each pixel, the number of spikes fired when the rat was in the pixel (obtained from the raw files) divided by the number of times the rat occupied that pixel (obtained from the occupancy array).

File format: The file is a binary file containing 32768 bytes. Each byte must be read out in the proper order as follows: First read out the firing rate map array. Each bin of the 64x64 bin firing rate map array is a floating point number, composed of 4 bytes. The first 64 entries correspond to the top row of the array, the second 64 entries correspond to the second row, etc. Immediately after the last entry of the last row (entry 4095), the occupancy array starts. Each entry of the occupancy array is an integer (4 bytes) that corresponds to the number of position samples counted when the rat was at that location. As with the firing rate array, the first 64 entries of the occupancy array correspond to the first row, the second 64 entries correspond to the second row, etc.
