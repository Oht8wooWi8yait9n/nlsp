Summary / Description

OBJECTIVES:
Wireless sensor network systems provide the infrastructure for easily and quickly deployable environmental sensors without requiring wired power or data interfaces. The network "motes" contain the processor and radio modules, as well as interfaces for a variety of sensor inputs. The Crossbow mesh network motes are self-organizing, with radio frequency (RF) signals either transmitted directly to the wired "gateway" (network interface) or multi-hopping mote-to-mote as needed to move about RF barriers until arriving at the gateway.

The objective of this experiment was to test the ease of setting up and reconfiguring a network of Crossbow motes with an on-board temperature sensor and acquiring the data via the gateway board attached to a laptop.

APPROACH:
Several configurations of the Crossbow mesh network were tested during the NEEMO 6 mission:

1. Laptop with gateway in main lock, motes deployed in entry lock and bunk area
2. Laptop with gateway in science area, motes deployed in main lock and bunk area
3. Laptop with gateway in bunk area, motes deployed in entry lock and main lock

Parameters recorded were the actual temperature data, as well as the number of hops per signal.

RESULTS:
Portability made it desirable. Improvements needed to HCI, as the evaluation used the developer's interface with a clumsy combination of NesC and Java in a Microsoft Windows environment.
